# ✨ Scroll-Aware Navbar & Text Animation Landing Page

An interactive and responsive frontend project demonstrating scroll-triggered UI effects using **HTML**, **CSS**, and **JavaScript**.

🔗 **Live Demo**: [View Project on GitHub Pages](https://ritikraj295.github.io/CODECRAFT_WD_01/)

## 🚀 Features

- **Navbar Color Change on Scroll**  
  The navigation bar dynamically changes its background color when the user scrolls down the page, enhancing the visual experience.

- **Text Scale-Up Animation**  
  Text elements smoothly scale up in size to draw attention as part of a clean and modern animation effect.

- **Responsive Layout**  
  Works well across various screen sizes including mobile, tablet, and desktop.

## 🛠️ Technologies Used

- **HTML5** – Structure of the web page  
- **CSS3** – Styling and animations  
- **JavaScript (Vanilla)** – Scroll detection and DOM manipulation
